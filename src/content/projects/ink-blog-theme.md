这个站点本身就是一个作品。做的起因很简单：试过很多博客主题，要么太"科技感"，要么一极简就显得寡淡，于是想做一个**有传统底子但不老旧**的版本。

## 设计思路

核心是中国画里的三件事：

- **墨分五色**——焦、浓、重、淡、清。整套配色不是"黑色 + 灰度"，而是一组偏暖的墨色阶，从宣纸白过渡到焦墨，这样层次才有"墨"的味道而不是"灰"的味道。
- **留白**——页面留白比常规博客更大，卡片边框细而淡，靠间距而不是分隔线来划分区域。
- **朱红点睛**——整站只有一种彩色，就是印泥的朱红。它出现在印章、链接、列表圆点、书页红丝这些很小的位置上，面积不大但让画面立住了。

## 技术要点

- **默认零 JavaScript**：全站静态生成，只有主题切换、分类筛选、目录高亮带一点原生脚本。禁用 JavaScript 后内容依然完整可读。
- **主题变量**：一套 CSS 变量控制全局配色，暗色模式只是换一组变量值，没有重复的样式规则。
- **宣纸纹理**：用 SVG `feTurbulence` 生成噪点，配 `mix-blend-mode: soft-light`。这里踩过一个坑——最初用 `multiply`，结果整页被压暗了约 25%，宣纸底直接变成灰底。
- **代码高亮**：Shiki 双主题输出，深浅色各自一套颜色变量。

## 关于可访问性

配色不是"看着差不多"就定下来的。辅助文字色一度只有 3.5:1 的对比度，低于 WCAG AA 要求的 4.5:1，后来把"淡墨"调深才达标。做视觉的时候很容易只顾好看，但文字读不清就是不合格。
